---
name: Production public origin
description: Canonical origin requirement for production callbacks and generated public links.
---

Use `https://trampolinenote.com` as the canonical production origin for OAuth callbacks and public links generated by the server.

**Why:** Runtime-managed deployment domains can resolve to the generated Replit hostname, while external OAuth clients are registered for the custom domain; that exact-string mismatch causes WHOOP to reject authorization.

**How to apply:** Keep the production `APP_BASE_URL` pinned to the custom origin. When the setting changes, republish before testing because production environment updates do not hot-reload into the live deployment.
