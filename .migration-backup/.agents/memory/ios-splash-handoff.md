name: iOS PWA splash handoff
description: Making the native apple-touch-startup-image hand off seamlessly to the in-app animated splash on installed iOS PWAs
---

FINAL OUTCOME (Jul 26, 2026, user-directed after three rounds of phone-only glitches): **do NOT try to pixel-match a designed static launch image to a live overlay.** The user ultimately asked for plain-black launch images + a loading spinner until the animated splash's assets are ready, on all devices. That eliminates the whole matching problem by construction. Prefer this pattern from the start for any future PWA splash work.

Durable lessons from the failed matching attempts (still valid if content-matching is ever attempted again):

- **Viewport offset**: with `apple-mobile-web-app-status-bar-style: black`, the iOS standalone web viewport starts BELOW the status bar, but the static launch image is centered on the FULL screen — viewport-centered content sits statusBar/2 lower and jumps at handoff (big on notched iPhones, invisible on iPads). `screen.height − window.innerHeight` measures the bar; `env(safe-area-inset-top)` is 0 in this mode. Even with the shift + icon preload/hold + entrance skip, the iPhone handoff never got glitch-free — hence the plain-image approach.
- **Icon/font pop-in**: anything painted before its image or webfont is loaded shows holes/FOUT swaps. Gate reveal on `img.complete && naturalWidth` + load/error listeners AND `document.fonts.load(...)`, always with a short safety timeout so it can't stick hidden.
- **Frozen boot second**: a React-rendered splash can't animate until the bundle boots — cold launches sit frozen ~1s. A pre-React splash must live in index.html as pure HTML + self-contained inline CSS + inline script; the React component renders null and only times fade-out + `.remove()` of that same node (no mid-animation snap). Include a dead-man self-fade (~15s) in case the bundle never boots.
- iOS snapshots launch images at add-to-home-screen time; users must delete + re-add the icon to see regenerated ones.

**How to apply:** splash implementation = the `#boot-splash` block in `client/index.html` (spinner → .ready reveal), launch images = plain solid `#0a0b10` PNGs (generated by a small no-deps Node PNG writer — sharp is NOT installed). Any index.html/launch-image change needs a sw.js CACHE bump (offline shell caches `/`).
