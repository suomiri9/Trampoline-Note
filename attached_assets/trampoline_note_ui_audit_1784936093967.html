Note Card (Training Log)
Too much crammed into one line of metadata
Date, time range, star rating, and WHOOP recovery/strain all sit in a single wrapping flex row in 10px mono text. On mobile it wraps unpredictably and the stars get mixed in with timestamps.
→ Split into two rows: date/time on top, ratings/WHOOP on a second row. Give stars their own visual space.
Skill grouping logic is visually complex
The card renders singles, connections (red), routines (blue badge), FC groups, and PART items all with different colours, badges, and ×reps=total maths inline. It's hard to scan at a glance.
→ Use a consistent row format: icon/badge · name · DD×reps. Collapse connection maths behind a tap. Limit badge colours to 2–3 max.
The ⋮ menu is the only way to edit
Tapping the card body does nothing — you have to find the tiny MoreVertical button. On mobile this is easy to miss.
→ Make the whole card tappable to open the edit dialog, keep ⋮ for delete only.
Note Dialog (Log Training Session)
Single tall form with too many sections
Date, time range, sleep, rating, skills search, practice list, connect-next, focus memo, and notes are all in one scrolling sheet. The note-dialog.tsx is 120KB — the largest file in the whole codebase.
→ Break into 2 steps: Step 1 = date/time/rating/sleep (quick). Step 2 = skills + notes (detail). Or use a tab strip inside the dialog.
CONNECT NEXT button is unclear
The red-outlined "CONNECT NEXT" button sits next to the search field with no tooltip or explanation. New users won't know what it does.
→ Rename to "+ Link" or "Chain" with a tooltip. Or move it inline after a skill is added (contextual rather than always visible).
Skills Page
Table + tabs + reorder mode + form + shape editor = too many modes
The skills page has: tab switcher (Skills/Drills/Connections/Archived), a reorder mode toggle, an add form, inline shape editing, a shape drafts editor, and a skill detail drill-down. All in one page.
→ Move Add/Edit into a bottom sheet. Move Archived into a separate route or a hidden section. Keep the main view as just the list + search.
Shape hierarchy not visually obvious
Parent skills and their shapes appear in the same flat table rows, differentiated only by indentation and a small chevron. Easy to lose track of nesting.
→ The dropdown tree you're already building is the right fix. Make sure the indent + colour contrast between parent and child is strong enough.
Score Page
Score form has too many optional fields visible at once
Fields like competitionId, round, synchro, doubleExecution, executionTwo are shown even for practice entries. The form feels like a tax return.
→ Show only: date, type (practice/comp), routine, E/DD/H/ToF, total. Reveal competition-specific fields only when type = competition.
Chart tab and list tab feel disconnected
The score history chart and the score list are on separate tabs, so you can't see a score in context while viewing the trend.
→ Put the chart at the top, list below it on the same scroll. Or make clicking a chart point highlight that score in the list.
Navigation & Global
Bottom nav has 6 items — too many for mobile
Training, Score, Stats, Skills, Routines, Settings all need to fit in the nav bar. Labels get tiny and mis-taps are common.
→ Reduce to 4 primary tabs (Log, Score, Skills, More). Put Routines and Settings under "More". This also frees up label width.
Points to Fix competes with Start Training
Both are primary-looking buttons in the header. "Points to Fix" is important but it's not the main action — it shouldn't fight Start Training for attention.
→ Make "Points to Fix" a ghost/secondary style, or move it to a persistent banner/widget below the header instead of next to the primary CTA.
Inconsistent border-radius across components
Cards use rounded-2xl, dialogs use various radii, badges use rounded-full or rounded-xl. The --radius token is 0.75rem but not applied consistently.
→ Pick one radius scale (sm=6px, md=12px, lg=18px, xl=24px) and apply it everywhere. Cards=lg, dialogs=xl, badges=sm.
